# etch_ui HMI — 초보자 가이드

> **대상:** 처음 WPF HMI를 켜 보는 운영자·발표 담당·유지보수 인력  
> **전제:** 제어(Start/Stop)는 **이 프로그램**에서만 합니다. Flask 웹은 **보기 전용**입니다.

---

## 1. 화면 한눈에 보기

```
┌─────────────────────────────────────────────────────────────────┐
│ 헤더: 사용자 · Flask/EtherCAT/데이터/AI엔진 칩 · 시뮬·데모 버튼   │
├──────────────────────────┬─────────────┬────────────────────────┤
│ 좌: 장비 도식 (가상 TM)   │ 중: 인터락  │ 우: 램프·Start/Stop    │
│  [도식확대][TM·스케줄]    │  · AI 요약  │  · FOUP 잔량         │
│  [센서 패널]              │  · 공정스텝 │                      │
├──────────────────────────┴─────────────┴────────────────────────┤
│ 하단: 운영 로그                                                  │
└─────────────────────────────────────────────────────────────────┘
```

| 영역 | 무엇을 보나요? |
|------|----------------|
| **좌측** | FOUP·TM·PM·듀얼블레이드 **가상 이송** 애니메이션 |
| **중앙** | 인터락 OK 여부, **AI 조언 요약**, 공정 스텝 |
| **우측** | 램프 4개, **시작·정지·리셋·유지보수** |
| **헤더 칩** | Flask·PLC·데이터 품질·AI 엔진 상태 |

**실측 센서 숫자·스파크라인**은 메인에 없고, **「센서 패널」** 분리 창에 있습니다.

---

## 2. 처음 켤 때 (PLC 없이 데모)

1. (선택) `etchflask` 실행 → [`docs/FLASK_초보자_가이드.md`](FLASK_초보자_가이드.md) 참고  
2. WPF 실행 → 로그인 `admin` / `Admin1234`  
3. 헤더 **「시뮬 허용: 끔」** 클릭 → **켬**  
4. 우측 **▶ 시작** → 가상 이송 시작  
5. 헤더 **Flask** 칩이 **OK**이면 웹·AI도 같이 갱신됩니다.

| 칩 | 정상(데모) | 의미 |
|----|------------|------|
| EtherCAT | **DEMO (시뮬)** | TwinCAT 없이 가상 운전 |
| 데이터 | **데모 시뮬** | 실측이 아닌 시뮬 값 |
| Flask | **OK** | 웹 서버 연결됨 |
| AI 엔진 | **ML** 또는 **규칙** | AI 추론 방식 (아래 §5) |

---

## 3. 분리 창(팝아웃) — 왜 쓰나요?

메인 화면은 **조작·요약**용입니다. 자세히 보려면 카드 제목 옆 버튼으로 **별도 창**을 엽니다.

| 버튼 | 창 제목 | 이렇게 쓰세요 |
|------|---------|----------------|
| **도식 확대** | 클러스터 도식 | 발표·모니터링용 **큰 도식**만 |
| **TM·스케줄** | TM · 스케줄 · 듀얼블레이드 | HOLD 이유, 파이프라인, 웨이퍼 타임라인 |
| **센서 패널** | 센서 · 추세 · 상태 | 압력·진동·온습도·Load Lock 접촉·그래프 |
| **인터락·AI** (중앙) | 인터락 · AI 모니터 | 레시피, 인터락 전체, **AI 근거 목록**, 모듈 |
| **제어 패널** (우측) | 제어 · 상태 램프 | **큰 Start/Stop** 버튼 |

**같은 버튼을 다시 누르면** 이미 열린 창이 앞으로 옵니다(중복 창 없음).

중앙 패널 안 **「↗ 인터락·AI 상세」** 도 **인터락·AI** 창과 같습니다.

## 4. 외부 모니터 · 항상 위 (2대 모니터)

### 4.1 언제 쓰나요?

| 상황 | 추천 |
|------|------|
| 노트북 + 외부 모니터 1대 | 메인 HMI는 **주 모니터**, **도식 확대** 또는 **TM·스케줄**을 **외부 모니터**로 |
| 발표(프로젝터) | **도식 확대**를 프로젝터 쪽에, 조작은 발표자 PC 주 화면 |
| 운전실 2인 | 한쪽은 WPF 조작, 다른 쪽은 **센서 패널**·**인터락·AI** 상시 표시 |

### 4.2 「→ 외부 모니터」 버튼

분리 창 **오른쪽 위**에 있습니다.

1. 분리 창을 연다 (예: **도식 확대**).  
2. **「→ 외부 모니터」** 클릭.  
3. 창이 **주 모니터의 오른쪽**(일반적인 2번 모니터 위치)으로 이동합니다.  
4. 창 모서리를 드래그해 크기를 맞춘 뒤 **창을 닫으면** 위치·크기가 **자동 저장**됩니다.

다음에 같은 분리 창을 열면 **마지막 위치**로 열립니다.

저장 파일: `{프로그램폴더}/data/hmi_popout_layout.json`  
(예: `bin/Debug/net8.0-windows/data/hmi_popout_layout.json`)

### 4.3 「항상 위」 체크

- 켜면: 다른 프로그램 위에도 분리 창이 **맨 앞**에 유지됩니다.  
- 운전 중 Excel·메모장을 보면서도 도식을 계속 볼 때 유용합니다.  
- 이 설정도 **창을 닫을 때 저장**됩니다.

### 4.4 모니터가 1대뿐일 때

「→ 외부 모니터」를 눌러도 창은 **주 모니터 밖**으로 나갈 수 있어 안 보일 수 있습니다.  
그때는 **Alt+Tab**으로 창을 선택한 뒤 **Win+←/→** 로 화면에 다시 붙이세요.

### 4.5 추천 배치 예시 (2모니터)

```
[모니터 1 — 주]              [모니터 2 — 보조]
 MainWindow (조작)            도식 확대 (항상 위 ✓)
                              또는 TM·스케줄
```

## 5. AI는 어떻게 보이나요?

| 위치 | 내용 |
|------|------|
| 헤더 **AI 엔진** | `ML` = 학습 모델, `규칙` = 스텁, `OFF` = Flask 미연결, `대기` = 아직 진단 없음 |
| 중앙 녹색 박스 | 이상 점수, 조치 문구, 예상 알람 요약 |
| **인터락·AI** 분리 창 | 세부 근거 목록(센서·스케줄·ML 신호) |
| Flask 웹 **AI 진단** 탭 | 같은 데이터를 브라우저에서 (문구 통일) |

**중요:** AI는 **조언만** 표시합니다. Start/인터락을 **자동으로 바꾸지 않습니다.**

Flask·학습 파이프라인: [`tools/ai/README.md`](../tools/ai/README.md) · [`docs/FLASK_E2E.md`](FLASK_E2E.md)

## 6. Flask 웹과의 관계

| | WPF (etch_ui) | Flask (etchflask) |
|--|---------------|-------------------|
| 역할 | **조작·인터락** | **조회·이력·AI** |
| Start/Stop | ✅ | ❌ |
| 주 사용 장소 | 현장 PC | 현장 PC 브라우저 또는 **모니터링 PC** |

Flask 쪽 화면·탭 설명: **[`docs/FLASK_초보자_가이드.md`](FLASK_초보자_가이드.md)** (etch_ui에 동봉, etchflask README에서도 링크)

## 7. 자주 묻는 질문

| 질문 | 답 |
|------|-----|
| **시작**이 비활성 | **시뮬 허용** 켰는지, 유지보수 모드 꺼졌는지, 작업자 이상 로그인인지 확인 |
| Flask **OFF** | `run_flask.bat` 실행 · URL `http://127.0.0.1:5000` · FarmUI와 동시 실행 금지 |
| 도식이 안 움직임 | **RUNNING**인지, **시뮬 허용**인지, **정지** 후 재개인지 확인 |
| AI가 `—`만 보임 | Flask OK 후 **6초 정도** 대기 · RUNNING 중이어야 sensor-data 전송됨 |
| 분리 창 위치가 이상함 | `data/hmi_popout_layout.json` 삭제 후 재실행 |
